## Como consultar a ajuda

Na página de ajustes, clique em **(?)** ao lado de uma categoria para abrir a seção correspondente. O menu **Opções → Documentação** abre este índice. Confira as descrições antes de selecionar um ajuste e revise o resumo antes de aplicá-lo.

As opções disponíveis variam conforme a versão, edição e build do Windows. Algumas alterações precisam de reinicialização. Os arquivos do Registro são referências técnicas: prefira a interface do programa para aplicar e restaurar ajustes.
